# Fast File Copier

A simple Windows desktop app to copy files faster using python multi-threading. Built to solve UI freezing during copy operations.

## Features
- Multi-threaded copying using ThreadPoolExecutor
- GUI built with CustomTkinter
- Cancel button that stops the copy process safely
- Handles permission errors without crashing

## Requirements
- Python 3.x
- customtkinter

## Setup & Running

1. Install requirements:
```bash
pip install customtkinter
```

2. Run the script:
```bash
python Fast_File_Copier.py
```

## Executable

- You can also download the standalone (.exe) from the [Releases section](https://github.com/mohamad931/Copy-File-Copier/releases/download/v1.0.0/FastFileCopier.zip) directly without needing Python installed.
